KNW-0000 · Change walkthrough

The cache now expires thumbnails after one hour

Thumbnails used to stay cached until a deploy cleared them. A stale image could survive for weeks. Each entry now carries an expiry, and the server rebuilds the thumbnail on the next request.

Component · Code, one block

One factory builds every database session in the process

get_session opens each session from this factory. The factory builds its session maker on the first call and reuses it after that.

ace-edge/core/db.py · session_factory, abridged
def session_factory() -> async_sessionmaker[AsyncSession]:
    if _state.sessionmaker is None:
        _state.sessionmaker = async_sessionmaker(
            bind=get_engine(),
            class_=AsyncSession,
            expire_on_commit=False,
            autoflush=False,
        )
    return _state.sessionmaker

expire_on_commit=False keeps attributes readable after a commit, so reading a committed row does not trigger a lazy refresh.

Component · Code, two blocks

The API commits a request's session after the handler returns

FastAPI calls get_db_session for each request that declares DbSessionDep. It wraps get_session from core.

1ace-edge/api/deps.py · get_db_session
async def get_db_session() -> AsyncGenerator[AsyncSession]:
    async with get_session() as session:
        yield session
        await session.commit()
2ace-edge/core/db.py · get_session, abridged
async with session_factory()() as session:
    try:
        yield session
    except Exception:
        await session.rollback()
        raise

get_session never commits. The caller decides when, and the API commits once per request.
